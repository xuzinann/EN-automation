The solution

A multi-agent system that runs the entire call end to end.

HTTP 418 ingests the project context, drafts the guide, conducts the live interview by voice, takes structured notes as it listens, and writes the final deliverable. Specialist agents handle each job; deterministic code keeps it on the rails.
